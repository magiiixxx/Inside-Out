# 03 — Students browse rooms

**What to build:** A student, without logging in, opens the site and
sees approved, recently updated rooms near PHINMA UI. They can filter by
maximum price and sort by distance.

**Blocked by:** 02

**Status:** done

- [x] Each room card shows price, distance from PHINMA UI, an
      available/occupied label, last updated and the owner's phone.
- [x] Sample rooms that are pending, rejected or not updated for more
      than 7 days do not appear.
- [x] A max-price filter narrows the list.
- [x] The list can be sorted by distance from PHINMA UI.
- [x] The page is readable on a phone.
- [x] Works on the live URL

**Cut first if time is short:** the price filter and the distance sort.
